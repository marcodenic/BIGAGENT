# Security

BIG AGENT 0.1 is a public alpha. Please report a suspected vulnerability through the repository's GitHub Security tab. If private reporting is unavailable, open an issue requesting a private contact without including exploit details.

The supported security boundary is one local operating-system user. BIG AGENT rejects remote network connections and browser-originated cross-site telemetry, but it does not attempt to isolate mutually untrusted processes running as the same user.
