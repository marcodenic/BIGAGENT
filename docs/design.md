# BIG AGENT design principles

BIG AGENT is ambient information, not a dashboard. At twelve feet, the status dot and one enormous sentence must tell the story. At the desk, a single detail line and timer add useful context. Inspection is intentionally secondary.

- Leave generous negative space; do not add cards or grids.
- A state is a verb: `THINKING`, `RUNNING TESTS`, `NEEDS YOU`, `DONE`.
- Attention states use amber/red and a restrained dot pulse. Normal work stays calm.
- The tiny ASCII face is optional personality, never the primary signal.
- Avoid detailed telemetry in the ambient view. Put recency, plans, and activity history behind inspection.
- Privacy mode replaces files, paths, commands, and details with generic activity.
- Respect reduced-motion preferences.
